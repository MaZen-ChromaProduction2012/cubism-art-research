## 📌 عن المشروع
موقع وبحث تفاعلي مصور يستعرض ثورة **المدرسة التكعيبية (Cubism)** في الفن التشكيلي الحديث، وكيف استبدل الفنانون المنظور الكلاسيكي الإقليدي ذي نقطة التلاشي الواحدة برؤية هندسية متعددة الأبعاد تجمع بين المكعبات، الأسطوانات، والمخاريط لاحتواء البعد الرابع (الزمن والحركة).

تم تصميم البحث وبرمجته ليكون عملاً أكاديمياً وبصرياً شاملاً، يدمج بين السرد التاريخي والفلسفي، دراسة تفكيك اللوحات العالمية، ومختبر رقمي حي يُمكّن القارئ من تجربة التفكيك التكعيبي بنفسه.

## 📖 محاور وفصول البحث
1. **المحور الأول — النشأة والجذور الفلسفية:** كيف بدأت الثورة التكعيبية في باريس (1907)، ومقولة بول سيزان الملهمة، والتأثر بالأقنعة الإفريقية.
2. **المحور الثاني — الخصائص البصرية والتقنية:** التسطيح الهندسي، المنظور متعدد الزوايا، إدخال البعد الرابع، وابتكار فن الكولاج.
3. **المحور الثالث — التحليلية مقابل التركيبية:** مقارنة مفصلة بين التكعيبية التحليلية (التقشف اللوني وتفتيت الأشكال) والتكعيبية التركيبية (الألوان الزاهية والكولاج).
4. **المحور الرابع — رواد الفن التكعيبي:** بابلو بيكاسو، جورج براك، خوان جريس، مع تسليط الضوء على التكعيبية في الفن التشكيلي المصري والعربي (حامد عويس، رمسيس يونان، جورج بهجوري).
5. **المحور الخامس — المعرض البصري المصور:** تفكيك تحليلي وهندسي دقيق لستة من أشهر اللوحات العالمية (آنسات أفينيون، الجورنيكا، كمان وشمعدان، بورتريه بيكاسو، المدينة، طبيعة صامتة مع قش الكراسي).
6. **المحور السادس — المختبر التفاعلي (Interactive Canvas):** مختبر برمجي يسمح للمستخدم بتوليد أشكال ومضلعات تكعيبية بنغمات لونية مختلفة وحفظ النتيجة كصورة.
7. **المحور السابع — الخاتمة والمراجع الأكاديمية:** توثيق كامل لأهم المصادر من أمهات كتب الفن والمتاحف العالمية (MoMA، Reina Sofía، دار المعارف).
8. **بطاقة الاعتماد والطباعة:** زر مباشر لتوليد نسخة ورقية منسقة رسمياً (Print / PDF) متوافقة مع معايير A4.

## 💻 التقنيات والأدوات المستخدمة
- **HTML5 Semantic Markup** — هيكلة دلالية متوافقة مع معايير الويب وقارئات الشاشة.
- **Tailwind CSS (CDN)** — تصميم عصري بنمط الواجهات الزجاجية الداكنة (Glassmorphism).
- **Custom CSS3** — دعم الطباعة المتجاوبة (Print Styles & @page)، شريط تمرير مخصص، وانسيابية التمرير ومسافة الهيدر (scroll-padding-top).
- **HTML5 Canvas API** — محرك المختبر التفاعلي للتوليد الهندسي العشوائي للأشكال التكعيبية.
- **SVG (Scalable Vector Graphics)** — رسومات هندسية متجهة عالية الدقة للوحات الفنية دون فقدان الجودة.
- **Google Fonts & FontAwesome** — خطوط عربية أصيلة (Cairo و Amiri) وأيقونات تفاعلية.

## 🚀 تشغيل المشروع ورفعه على GitHub Pages

### 1. التشغيل المحلي (Local)
المشروع يعمل كصفحة واحدة ذاتية الاحتواء (index.html). يمكنك ببساطة فتح الملف في أي متصفح ويب حديث.

### 2. التفعيل على GitHub Pages (للحصول على رابط مباشر):
1. ارفع ملفات هذا المجلد إلى مستودع جديد على حسابك في GitHub (مثلاً: cubism-art-research).
2. ادخل إلى إعدادات المستودع **Settings**.
3. من القائمة الجانبية، اختر **Pages**.
4. تحت قسم **Build and deployment**، اختر:
   - **Source:** Deploy from a branch
   - **Branch:** main والمجلد / (root).
5. اضغط **Save**، وخلال دقيقة سيظهر لك الرابط الحي لمشاركته مع المعلمة والزملاء.
